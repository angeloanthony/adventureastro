## 为什么要在 Red Fleet 露营

大多数计划来 Vernal 一带的人，都会围绕那些响亮的名字安排住宿——<a href="/dinosaur-national-monument/visiting-dinosaur-national-monument/">Dinosaur National Monument</a>、<a href="/guides/ultimate-guide-to-flaming-gorge/">Flaming Gorge</a>——而 Red Fleet 就算被提起，也只是当作一个匆匆的午后停靠点。但作为一个*露营*的地方，这其实是错过了机会。Red Fleet 把一趟异常令人满足的旅程，装进了一个小巧而宽容的包裹里：一处成熟营地，紧挨着温暖的红岩水库，往南十分钟就是设施齐全的城镇，划一段船就能看到真正的恐龙脚印，而游泳、钓鱼、桨板全都在营地边上。

它作为露营目的地的特别之处不在规模，而在于*轻松与回报*。在 Flaming Gorge 露营给你的是宽阔、深邃、戏剧化的大水面，去<a href="/guides/ultimate-guide-to-ashley-national-forest/">Ashley National Forest</a> 高处露营给你的是凉爽的松林和独处，而在 Red Fleet 露营给你的，是本地区阻力最小、回报最高的一次家庭之夜。你到达后几分钟内就能扎好营、下到水里；第二天一早，孩子就能沿着一块砂岩板去描摹恐龙的脚印。世上很少有营地，能让你在漆黑的荒漠星空下入睡，醒来时离这样的东西只有几步之遥。

这里的景致也配得上它。水库被倾斜的纳瓦霍砂岩地层环抱——正是这支“红色舰队”给了公园名字——它们在日出和日落时发光，在平静的早晨映在水面上。它拍出来像一座名气大得多的公园，却很少挤满人；而它紧凑、低调的布局，恰恰是它对新手露营者和家庭如此宽容的原因：好走、好进出，也好和本地区更大的景点搭配。

而露营，才是解锁 Red Fleet 最好时光的钥匙。当成一日游，它是愉快的几个小时；住上一夜，它就变成了更好的东西。住在营地，你可以趁清晨凉爽走那条毫无遮蔽的足迹点路线，赶上水面平如镜时划船和拍倒影，从自家门口的岸边钓黎明那一档，并在白天人群到来之前和散去之后，几乎独享整片地方。本攻略讲的是*如何*把它露好。想了解公园本身的全貌——历史、地质、足迹点的故事，以及所有可玩的项目——请搭配阅读<a href="/guides/ultimate-guide-to-red-fleet-state-park/">Red Fleet State Park 终极攻略</a>；想知道 Red Fleet 在本地区其他露营地中的位置，可以从<a href="/camping/">露营专区</a>开始。

## 露营区域总览

和本地区那些绵延的水库与森林目的地相比，Red Fleet 简单得让人松一口气。它不是散落在几十英里之间的一堆营地，而是围绕一座水库建起的、单一而紧凑的州立公园——这意味着“在 Red Fleet 该住哪儿”，与其说是在遥远的区域之间做选择，不如说是在同一个营地里挑对*营位*，以及决定公园本身是不是你最好的基地，还是你更愿意住在城里、白天开车过来。

大体上，这里的露营可以分成几种选择：

- **Red Fleet 营地。**公园在水库附近有一处成熟营地——这是园内的选项，也是能带来招牌体验的那个：红岩湖畔的一夜，水就在离帐篷几分钟的地方。这是 Red Fleet 露营的核心，也是本攻略的重点。
- **临水营位与靠里的营位。**营地内部，有些营位更靠近水面和视野，另一些则更靠里、更避风。哪种更好取决于你的优先级——是黎明划船和倒影，还是多一点树荫和遮蔽。具体哪些营位在哪个位置、水有多近，会随水库水位和管理方式变动。
- **邻近的 Steinaker 州立公园露营。**Red Fleet 的邻居、往城里方向几分钟处的 <a href="/guides/ultimate-guide-to-steinaker-state-park/">Steinaker State Park</a>，提供了第二处暖水水库营地——如果 Red Fleet 订满了，这是天然的替代或分流选择，在较长的行程里也很好搭配（见下文对比）。
- **以 Vernal 为基地。**如果家里有很小的孩子、正赶上连续的雨天，或者你只是想在一天结束时洗个热水澡、吃顿餐厅，那么住在 <a href="/guides/ultimate-guide-to-vernal-utah/">Vernal</a>——南边十分钟车程，有酒店、私营房车营地和完整服务——白天再去 Red Fleet，也是一个舒服的替代方案。

第一次来的实用结论：**这座公园小到主要决定只剩下订哪个营位、以及多早去订**——所以夏季请提前预订，让它的小巧成为你的优势。由于营位、布局和配套设施都会变化，水库水位也会移动岸线，请<strong>请向官方渠道核实</strong>（Utah State Parks）确认当前的营地详情和营位细节，再据此做任何安排。

<div class="article-tip"><strong>让营位配合计划：</strong>以划船和看足迹点为主的行程，最适合选一个能让你迅速下水、赶上平静清晨出发的营位；家庭游泳行程需要方便去沙滩、又能在正午躲阴的位置；摄影行程则希望有一条通往“舰队”地层的开阔视线，用来拍日出和日落。先想清楚你的早晨长什么样，再订那个离它最近的营位——并且在公园订满时，把 Steinaker 或 Vernal 当作备选。</div>

## 成熟营地

在 Red Fleet 露营，公园的成熟营地就是那个选择，而且是个不错的选择。这里所说的成熟营地，指的是有指定营位、附近配有基础设施——通常是犹他州立公园会提供的那类配套——坐落在水库的红岩景色中，方便前往水边、沙滩和足迹点登山口。它是 Red Fleet 露营的骨干，对绝大多数游客来说，也正是那个对的选择。

它的吸引力很直白：你能享受公园的景色和亲水条件，却不必承担原始露营的种种要求，而且是在一个管理有序、适合家庭的环境里，帐篷和房车都行得通，离城又只有几分钟。因为 Red Fleet 是一座设施完善的州立公园，它的营地比 Uintas 山上那些质朴的森林营地、或 Flaming Gorge 那些分散的水库营地更温和、更可预期——这在很大程度上就是它为什么这么适合带孩子露营，或者适合新手练手。

因营位而异、而本攻略绝不会替你编造的，是那些具体信息：营地**有多少个营位**、**哪些（如果有的话）提供水电接口**、有没有**排污站**和**饮用水**、**营位最大车长**是多少、营位是**可预订还是先到先得**、**费用**多少，以及**季节性的开放和关闭日期**。这些全部由 Utah State Parks 设定，而且年年都在变。Red Fleet 还是一座收费公园——有日间使用费、露营费和下水坡道费——犹他州立公园通票可能涵盖日间使用；请确认哪一条适用于你的行程。

<div class="article-tip"><strong>订之前：</strong>关于当前的营地详情——营位、配套、水电接口、饮用水情况、费用和预订窗口——请<strong>请向官方渠道核实</strong>（Utah State Parks 及官方预订系统）。夏季周末和假日请尽早预订，最好、最靠水的营位总是最先没；同时准备一个备选方案——Steinaker 或 Vernal 的私营房车营地——以应对高峰日期。</div>

## 房车露营

Red Fleet 是一个轻松、省心的房车目的地，对不少家庭来说，这也是享受这座公园最舒服的方式——在高原荒漠炎热的一天结束时，你有自己的床、厨房和空调，而且离城只有几分钟，缺什么随时能补。作为一座设施完善的州立公园，营地通常可以停放房车和拖挂车，而从 US-191 拐进来的那段铺装路又短又好走，比 Uintas 山上蜿蜒的林道容易得多。对于既想要温水水库和恐龙冒险、又不想应付偏远大目的地那套后勤的房车旅行者来说，Red Fleet 很难被超越。

对房车客最关键的那几个变量，恰恰也是变动最频繁、我们绝不会替你编造的，所以请把每一条都当作需要确认的事项，而不是想当然：

- **水电接口**——某个营位是否提供电、水或排污接口。设施完善的州立公园营地往往比私营房车营地更基础，所以除非你已经确认过，否则请按自给自足来准备。
- **排污站和饮用水**——是否提供、位置在哪都因地而异且可能变化；如果没确认过水源，请自带饮用水。
- **营位最大车长和直进直出营位**——小公园的营位可能比大水库的环线更短更窄，所以大车在决定之前要先确认能不能停下。
- **预订**——适合房车的营位在夏季周末最先被订走；凡是可预订的营位，请尽早下手。

<div class="article-tip"><strong>房车现实核查：</strong>Red Fleet 适合大多数车型，拖车也很轻松，但如果一定要有完整的水电接口，<a href="/guides/ultimate-guide-to-vernal-utah/">Vernal</a> 城内及周边的私营房车营地更稳妥，公园就在十分钟车程外，当日往返即可。关于任何具体营位的水电接口、排污站、饮用水和车长限制，请在把车拖进来之前<strong>请向官方渠道核实</strong>（Utah State Parks）——夏季也请尽早预订。</div>

想了解整个地区更全面的房车选项——包括 Flaming Gorge、森林和 Vernal 的私营营地——请看<a href="/camping/">露营专区的房车部分</a>，并用我们的<a href="/guides/what-to-bring/">装备清单攻略</a>来打包。

## 帐篷露营

对帐篷露营者来说，Red Fleet 是块宝地：你可以在能看见红岩水库的地方扎营，醒来时看着“舰队”地层被第一缕光点亮，然后在天气变热、人群到来之前下到平静的晨间水面——或者走上足迹点步道。成熟营地提供带指定帐篷位、附近有配套设施的选择，而公园紧凑、宽容的布局，让它成为本地区最适合带孩子扎帐篷、或者新手上手的地方之一。

真正需要围绕规划的是**高原荒漠环境**，而不是帐篷本身。这里是暴露的高海拔荒漠地带：夏日白天可能酷热、阳光强烈，即便午后再灼人，夜里也可能凉得出人意料，而午后常有大风和偶发的雷暴。地钉要打牢，睡袋要比正午的热度所暗示的更保暖，扎营时要同时留意日照和风向。这片开阔地带树荫稀少，所以一个有些天然遮蔽的营位——或者你自带的一顶好天幕——在一天中最热的时候会很值。

帐篷露营是体验 Red Fleet 最灵活、成本最低的方式，也最能让你贴近水面和光线，赶上黎明的划船和黄金时刻。它同样是这里经典的“第一次露营”配置，因为公园小、离城近、又容易应付：是一个适合磨合新装备、或者带孩子第一次在户外过夜的宽容之地。如果你想要更凉的夜晚和森林的树荫，而不是开阔的红岩，<a href="/camping/camping-in-ashley-national-forest/">Ashley National Forest</a> 的营地往上开一小段海拔就到；如果你想要更大的水面，<a href="/camping/camping-at-flaming-gorge/">Flaming Gorge</a> 在北边一小时车程处。用<a href="/guides/vernal-weather-guide/">Vernal 天气攻略</a>来安排出行时间，它逐月介绍了本地区的炎热、寒冷和风暴规律；并用我们的<a href="/guides/what-to-bring/">装备清单攻略</a>来应对温差。

## 家庭露营

Red Fleet 可能是 Vernal 附近最适合家庭露营的地方，而它赢得这个称号的方式，是让露营*更容易成功*——当有孩子在场时，这就是全部重点。从一个小营地出发，全家能够去温暖的水库游泳、在平静的水面划船、在温和的岸边钓鱼、走上一块真实的恐龙脚印石板，而城镇就在十分钟外，随时应付那件必然会忘带的东西。它几乎一次性命中了孩子的每一项优先事项，而且是在一个低压力、紧凑的环境里，没有哪件事需要长途驾车或重大投入。

在这里过一个愉快的家庭露营周末，公式很简单：

- **第一次露营就短一点、近一点。**Red Fleet 距离 Vernal 十分钟，这是优点——一次说走就走的过夜，或者一次可以随时中止、随时补给而不必手忙脚乱的初次露营。想要最省事的入门，更近的邻居 <a href="/guides/ultimate-guide-to-steinaker-state-park/">Steinaker</a> 还要再简单一点；而 Red Fleet 多了那份让人记住的恐龙冒险。
- **恐龙足迹要趁早去。**足迹点路线是暴露的高原荒漠，几乎没有遮蔽，所以请在凉爽的清晨出发，带上帽子、防晒霜和充足的水——这样一场小冒险，能把一次露营变成孩子记得住的故事。
- **救生衣，永远穿着。**这里**没有救生员**，温暖的表层水下面更冷。让不会游泳的人和孩子在水库上和水边始终穿着救生衣，并全程紧盯。
- **让一天有弹性。**游泳、划船、一段岸边钓鱼、安静的营地时光交替进行；公园足够小，你可以随着气温和孩子的精力随时改计划。
- **为烈日和干燥做准备。**树荫稀少、空气干燥；水、零食和防晒装备都要比你以为需要的更多，并为炎热的白天和凉爽的夜晚做好准备。

在这里，露营——而不是一日游——才是让家庭之行变得特别的原因，因为它给了你凉爽平静的早晨和安静的傍晚，而这些是白天的人群永远看不到的。更多以孩子为中心的点子，请看<a href="/things-to-do/fun-things-to-do-vernal-utah-kids/">带孩子在 Vernal 好玩的事</a>；想把足迹之外的化石那一面补上，请看<a href="/dinosaur-national-monument/visiting-dinosaur-national-monument/">Dinosaur National Monument 攻略</a>。

## 恐龙足迹点的抵达方式

恐龙足迹点是 Red Fleet 的头号看点，而在公园里露营是体验它的最佳方式。关于这些脚印的完整故事——数百个距今约两亿年的早侏罗世脚印，保存在水库边一面倾斜的砂岩表面上，以及如何去看它们——属于<a href="/guides/ultimate-guide-to-red-fleet-state-park/">Red Fleet State Park 终极攻略</a>。而*对露营者*来说重要的是时机和抵达方式：住在园内，让你能在唯一真正舒适而值得的时段抵达足迹点——清晨，凉爽，在高温和大风之前。

抵达脚印通常有两种方式，而露营让这两种都更好：

- **走步道。**一条徒步路线从公园的登山口沿水库通往足迹点。这是最直接的选择，但它是一段暴露在高原荒漠中、几乎没有遮蔽的行走——这恰恰是露营者的优势所在：你可以在天刚亮时就上路，赶在太阳把它变成烤箱之前，而不是从城里开一小时车、上午过半才到。
- **走水路。**很多人会划皮划艇或桨板，直接横渡水库到足迹点所在的岸边，这缩短了陆上步行，也把一次参观变成了一场小冒险。水面平静时，这是本地人最爱的方式——而这里的平静是清晨才有的现象，这又是露营（并在黎明下水）胜过一日游的另一个理由。

<div class="article-tip"><strong>保护这些脚印：</strong>足迹点是不可复制的科学与文化资源。绝不要为了拍照“增强”效果而触摸、描粉笔、翻模、泼水或往脚印上倒任何东西，不要堆石头或涂鸦，也绝不要试图带走任何东西——像这样的遗址已经被破坏和盗取所损害。只看、用自然的低角度光线尊重地拍摄，并让它保持你见到时的样子。因为这些脚印暴露在水边，通行情况可能受水库水位和天气条件影响。在把行程建立在它之上之前，请<strong>请向官方渠道核实</strong>（Utah State Parks）确认当前的步道距离、路线和通行状况。</div>

露营者的做法很简单：把参观足迹点安排在第一个早晨，趁天凉、水面如镜时在黎明出发，带的水比你以为需要的更多，并善待这处遗址。然后在逐渐变热的一天里，回到营地游泳、划船、钓鱼。

## 从营地钓鱼

对很多露营者来说，黎明和黄昏在岸边钓一场，是一次露营行程安静的核心——而 Red Fleet 正是为此而生。露营把你放在鱼最活跃、白天人群已经散去的弱光时段的水边，而公园这片小而遮蔽良好的水库，是一个平易近人、适合全家的钓点，无论岸钓还是船钓，都不必应付大水面的距离和后勤。它不是 Flaming Gorge 那样的猎奇目的地；它是在一次家庭露营中可以说更有用的东西——一处轻松宽容的渔场，孩子真的能从岸边钓上鱼来。

Red Fleet 通常以**虹鳟**闻名，同时也有**鲈鱼**和**蓝鳃太阳鱼**等暖水鱼种，让钓鱼人一年四季都有变化可选。露营会改变你钓它的方式：从一个湖畔营位，你可以在早饭前走到水边甩一竿；而它紧凑的尺寸意味着岸钓的人——不只是船钓的人——真的有机会，这对孩子和新手来说再合适不过。从营地出发，钓平静的黎明和黄昏两档；一旦午后起风或有风暴形成，就赶紧离开开阔水面。

<div class="article-tip"><strong>下竿之前：</strong>必须持有有效的犹他州钓鱼许可证，而鱼种、放流、限额和法规都会随时间和水域变化。下竿前请<strong>请向官方渠道核实</strong>（Utah Division of Wildlife Resources）确认 Red Fleet 当前的鱼种、许可证和限额。想知道具体怎么钓这片水，请看我们专门的<a href="/fishing/fishing-red-fleet-reservoir/">Red Fleet 水库钓鱼攻略</a>；想知道它在本地区各处水域中的位置——包括 Gorge 那处招牌级的大鱼钓场——请看<a href="/fishing/">恐龙之乡钓鱼</a>。</div>

## 桨板与皮划艇

划船大概是你在 Red Fleet 营位上能做的最好的事——而且它还独一无二地兼具一个身份：通往恐龙足迹点的路线。水库遮蔽良好、面积紧凑，在无风的早晨水面平静；红色砂岩地层构成了壮观的背景；而朝着一片有两亿年历史的脚印岸线滑行过去，是那种旅程结束很久之后仍然留在人心里的体验。对露营者来说，回报在于时机：你已经在园内，可以在黎明下水，那时水面如镜、光线最好，而不是上午过半才赶到，迎接你的是风和碎浪。

有几条实际做法，能让以营地为基地的划船顺利进行：

- **从营地早点出发。**早晨通常最平静；午后起风会把水面吹皱，划船和拍倒影都会更难。就住在水边正是全部优势所在——用它换一次天光初亮时的下水。
- **穿好救生衣。**温暖表层之下是冷水、没有救生员、又是开阔水面，这意味着所有人都要穿救生衣，孩子尤其如此。
- **自带装备，或先确认租赁。**园内是否提供租赁会变化——在把计划押在“到公园租一艘皮划艇或桨板”之前，请<strong>请向官方渠道核实</strong>（Utah State Parks）；很多露营者都是自带装备。
- **留意足迹点那段岸线。**如果你划船去看脚印，请小心靠岸，并像任何徒步者一样，以同样的尊重和小心对待这处遗址。

划船也是最温和的方式，能在一片平静的小水库的安全范围内，给孩子一种真实的冒险感——是家庭露营行程天然的核心项目。想了解更完整的划船情况，<a href="/guides/ultimate-guide-to-red-fleet-state-park/">Red Fleet 目的地攻略</a>对水库上的活动有更深入的介绍。

## 游泳

在 Uintah Basin 炎热的夏日里，Red Fleet 的水库是实打实的解脱，而游泳是在这里露营最大的乐趣之一。水温会随季节慢慢升高，有一片可以涉水和晒太阳的沙滩区，而红岩的背景胜过任何市政泳池——正是这种轻松又清凉的回报，让一次炎热的露营对全家人都值回票价。露营意味着你可以在清晨徒步看完足迹点、早上划完船之后，趁温暖的午后下水，然后在人群散去的黄昏再凉快一次。

最关键的告诫，和这座水库的一切规则一样：**这里没有救生员。**请紧盯孩子，让不会游泳的人穿好救生衣，并记住即使表层摸上去温暖，水温也会随深度下降。在这里游泳是暖季活动——盛夏之外的月份，水往往冷得不舒服。下水前请<strong>请向官方渠道核实</strong>（Utah State Parks）确认当前的指定游泳区、水况和任何季节性警示。

## 摄影建议

在 Red Fleet 露营，同时也是一次摄影之旅，而露营就是那件秘密武器——它让你在黄金时刻和暗夜星空下就位，那时一日游的人已经走了，而“舰队”正在发光。

- **在营地拍黄金时刻。**露营意味着日出和日落时你已经在湖畔，那时纳瓦霍砂岩地层泛出最浓烈的红；正午则会把色彩拍平。这里清晨和傍晚的光就是一切，而只有露营的人才能稳稳地两头都赶上。
- **在黎明追倒影。**平静的晨间水面会映出红色地层，那是这座公园的招牌画面——要在起风之前出门，而在这样一片小水库上，起风来得实在很早。
- **利用划船的视角。**皮划艇或桨板把你放在水平面上，可以拍出地层和岸线独特的低角度构图；注意保护你的器材不进水。
- **尊重地拍摄足迹点。**用自然光和低角度去表现脚印的深度——但绝不要为了“拍得更好”而描粉笔、泼水或触摸脚印，那会毁掉这处资源。
- **拍好暗夜星空。**远离城镇的 Red Fleet，在晴朗无月的夜里能拍出极佳的星空和银河——这是选择露营而不是一日游的真正理由。
- **看天，为安全。**夏日的雷雨云能堆出戏剧性的背景，但也会给开阔水面和裸露岩石带来雷击风险——风暴逼近时，请离开水面、离开高处。

## 野生动物

在 Red Fleet 露营，意味着你身处高原荒漠与水域交界的地带，而几个习惯能让你和动物都安全。最重要的是**食物存放**：把所有食物、垃圾和有气味的物品收好——放在硬壳车辆里，或按营地张贴的规定处理——绝不要放在帐篷里，以免把动物引进营地。每顿饭后彻底清理干净，所有残渣都带走；装备也要收好，免得小动物一夜之间啃出个洞。

对于一座小公园来说，Red Fleet 的野生动物种类相当不错。在山艾和岩石之间，你可能看到**骡鹿**、**长耳大野兔**、**棉尾兔**、**蜥蜴**和各种荒漠鸟类；而水库会把**水禽**和其他鸟类吸引到岸边——在早晚柔和的光线里，这是随意观鸟的好去处，而那恰恰是露营者在外面活动的时候。和在高原荒漠中一样，请给动物留出空间，绝不要投喂野生动物。在多岩的地面上要留意手脚放在哪里，因为这一带有**响尾蛇**出没；黎明和黄昏往返营地开车时，也要留意路上的动物。

<div class="article-tip"><strong>提示：</strong>具体的野生动物安全和食物存放要求可能因营地和区域而异，也可能随天气条件变化。请遵守你所在营地张贴的所有规定，给所有野生动物留出充足空间，并<strong>请向官方渠道核实</strong>（Utah State Parks）确认你露营地点当前的相关要求。</div>

## 无障碍情况

作为一座设施完善的州立公园，Red Fleet 在日间使用区和营地区域通常提供无障碍停车位和基础设施，而水库大部分岸线和沙滩体验都离停车处不远——这往往让这处成熟营地，成为比森林里的原始营位和分散营位、或大水库更崎岖的角落更方便的露营选择。紧凑、以铺装通道为主的布局，也是这座公园对各类游客都很友好的原因之一。

不过，前往**恐龙足迹点是一条未铺装的高原荒漠路线，地面起伏不平**，而抵达脚印——无论徒步还是划船——都会涉及并非处处无障碍的地形。由于具体的无障碍营位和设施因时而异且会变化，如果你有特定需求，出行前请<strong>请向官方渠道核实</strong>（Utah State Parks）确认当前的无障碍配置。

## 周末露营行程

一个周末是 Red Fleet 经典的露营行程，两晚足以把这座公园玩透，还能顺带延伸到更大的区域。这份行程围绕露营者最大的优势设计：清晨的凉爽与平静。

**第 1 天——抵达、扎营、下水。**上午晚些时候离开 <a href="/guides/ultimate-guide-to-vernal-utah/">Vernal</a>——只要十分钟——在你订好的营地扎营，然后把温暖的午后交给水库：去沙滩游个泳，在红岩地层之间划一趟船，或者带孩子在岸边轻松<a href="/fishing/fishing-red-fleet-reservoir/">钓</a>一场。趁光线在“舰队”上变得柔和温暖时做晚饭，然后熬到满天星斗。

**第 2 天——黎明看恐龙，白天玩水。**早起，趁天凉、水面如镜时抵达**恐龙足迹点**——可以从营地走步道，也可以划船横渡水库到达，尊重地拍下这些脚印。回到营地后，在温暖的午间游泳、划船、钓鱼，然后享受第二个红岩日落和一个安静的夜晚。如果有车又还有精力，午后也是把这些足迹和<a href="/dinosaur-national-monument/visiting-dinosaur-national-monument/">Dinosaur National Monument</a> 的**化石**搭配起来的天然窗口——它就在东南方向不远处，能补全整个恐龙故事。

**第 3 天——最后一个早晨，然后回家或继续上路。**再享受一次水上的黎明——甩一竿、划一趟，或者在水库边喝杯咖啡——收拾营地，然后要么轻松开回 Vernal，要么接着奔向更大的一天：北上去 <a href="/camping/camping-at-flaming-gorge/">Flaming Gorge</a> 看大水面，上山进 <a href="/camping/camping-in-ashley-national-forest/">Ashley National Forest</a> 吹凉爽的山风，或者在本地区的<a href="/scenic-drives/">景观自驾</a>路线上兜一圈。

这就是最典型的轻松家庭周末：在温暖的红岩水库边住两晚，黎明来一场恐龙冒险，而每一天的首尾都是最好的光线和最安静的时段。从西边过来？请看我们的 <a href="/from/salt-lake-city/">盐湖城到 Vernal 攻略</a>了解路线。

## 计划要点

用一份简单的计划把这一切串起来：

- **夏季尽早预订。**最好、最靠水的营位在夏季周末和假日会被订满。请<strong>请向官方渠道核实</strong>（Utah State Parks 及预订系统）确认预订窗口并提前下单，同时把 Steinaker 或 Vernal 的私营房车营地留作备选。
- **核实费用、配套和开放时间。**Red Fleet 是收费公园，有日间使用费、露营费和下水坡道费，而它的营位、水电接口、供水和季节性营业时段年年都在变——绝不要想当然；出发前先确认。
- **趁清晨凉爽去足迹点。**这条路线是暴露的高原荒漠；请在黎明出发，带好防晒装备和充足的水，并善待这些不可复制的脚印——只看、只拍，让它们保持不被触碰。
- **在水边始终穿好救生衣。**这里没有救生员，温暖的表层水下面更冷；孩子在水库上和水边时请全程紧盯。
- **为平静时段扎营和下水。**早晨是划船、拍倒影和钓鱼最平静的时候；请早点下水，并在午后起风或有风暴形成时上岸。
- **为高原荒漠的温差打包。**炎热的白天、凉爽的夜晚、强烈的阳光、稀少的树荫和午后的大风都会出现——请带上分层衣物、防晒装备、一顶天幕，以及比你预计更多的水。
- **务必查看当前的火源限制。**干旱时期常有禁火令；绝不要想当然地认为可以生营火，在生任何火之前先确认这座公园的规定。
- **以 Vernal 为补给基地。**燃油、食品、渔具和户外装备都在十分钟车程外的城里——天气变坏时这是很好的退路。请用我们的<a href="/guides/what-to-bring/">装备清单攻略</a>来打包。
- **搭配着玩。**Red Fleet 最出彩的时候，是和附近的州立公园、纪念地，或者一天的山区或大水面行程组合起来——把它编进一份更大的<a href="/camping/">恐龙之乡露营计划</a>里，而不是当成一个孤立的停靠点。

带着计划来露营，Red Fleet 会给你一种很少有地方能用同等付出换来的旅程——离城几分钟的温暖红岩水库、黎明划一段船就能抵达的恐龙冒险、营地边轻松的钓鱼、游泳和观星，而且很少需要和人群分享。挑好营位并尽早预订，趁凉爽的清晨去足迹点，让孩子穿好救生衣，核实那些会变的细节，然后让这座小而慷慨的公园，成为一趟更大的恐龙之乡之旅轻松的锚点。而当你想在两晚水边生活之间，把营位换成一场由向导带队的荒野冒险时，<a href="/booking/">预订一次 Adventure Tours Vernal 的 UTV 行程</a>，让 Dave 和 Trudy 带你去看水库之外的这片土地。
