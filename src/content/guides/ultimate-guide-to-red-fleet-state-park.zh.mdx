## 为什么值得去 Red Fleet State Park

大多数游客来 Vernal 一带都是冲着那些大名鼎鼎的地方——Dinosaur National Monument、Flaming Gorge——就算听说过 Red Fleet，也往往把它当成可有可无的补充。这是个错误。Red Fleet 把一套异常令人满足的体验塞进了一个小巧轻松的包裹里：上午你可以站在布满真实恐龙足迹的岩面上，中午就已经泡在温暖的红岩水库里游泳了，而这一切都在离镇上十英里以内。

光是风景就值回票价。水库被壮观的 Navajo 砂岩岩体环抱——这就是园名里的那支“红色舰队”——它们在一天的首尾时分泛着光，在无风的清晨倒映在水面上。这种地方拍出来像某座名气大得多的公园，却几乎没什么人。而且因为它紧凑又低调，所以很包容：好找路、对家庭友好，也很容易和周边更大牌的景点搭配。

对于以 Vernal 为基地的行程来说，Red Fleet 是完美的节奏调剂——半天的恐龙与水上时光，恰好卡在国家纪念地和山区行程之间。它所在的这一片目的地群还包括邻居 <a href="/zh/guides/ultimate-guide-to-steinaker-state-park/">Steinaker State Park</a>、<a href="/zh/dinosaur-national-monument/visiting-dinosaur-national-monument/">Dinosaur National Monument</a> 的化石，以及 <a href="/zh/guides/ultimate-guide-to-ashley-national-forest/">Ashley National Forest</a> 的高山地带。想了解它们之间怎么串起来，先看我们的 <a href="/zh/guides/ultimate-guide-to-vernal-utah/">Vernal 终极攻略</a>。

## 历史

Red Fleet 水库是一片铺在极其古老地貌之上的人造景观。水库由拦截 Big Brush Creek 筑坝而成，用来为周边盆地蓄水——它是 Uintah Basin 修建的众多水库之一，服务于牧场、农业和社区。随着蓄水完成，这里形成了后来成为 Red Fleet State Park 的休闲区，如今由犹他州的 Division of State Parks 管理。大坝的建成年份和公园的设立沿革，<strong>请向官方渠道核实</strong>（Utah State Parks）。

公园的名字来自它最醒目的特征：三座巨大而倾斜的红色 Navajo 砂岩岩体从水中升起，从合适的角度看去，就像一支下锚船队的风帆与船身。正是这个航海意象让“Red Fleet”得名，也一直是这座公园的视觉标志。

但这片场地真正的历史，比任何水库都要深远得多。在这里还没有水之前，这里是一片古老环境边缘的沙地与泥地，恐龙曾从上面走过——其中一些脚印被压进石头，留存至今。那片出露在水库边缘的恐龙足迹，把一个现代休闲区和大约两亿年前的某个瞬间连在了一起。

## 地质

定义了 Red Fleet 的岩石是 **Navajo 砂岩**，正是这套标志性地层造就了犹他州南部大部分最著名的红岩风景。它最初是早侏罗世覆盖整个区域的沙漠中一片巨大的风成沙丘，直到今天你仍能从崖壁上那些扫掠般的交错层理线条中读出它的来历——那是被石化的沙丘斜面，凝固在流动的中途。

在数百万年里，这些沙丘被掩埋、胶结成岩，然后被抬升、侵蚀，成了今天环绕水库的那些倾斜而雕塑感十足的岩体。红色来自氧化铁——也就是铁锈——对砂岩的浸染，正是它让这支“舰队”在日出和日落时分燃烧般发亮。

恐龙足迹也属于同一个地质故事。这些脚印形成于一层沙与泥的表面，后来变硬并被保存下来，而水库边缘那片出露的倾斜岩石，本质上就是这片远古地貌被翻转向上的一页。关于这些岩层在整个区域如何被倾斜、被切割的更宏观地质故事，我们的 <a href="/zh/dinosaur-national-monument/visiting-dinosaur-national-monument/">Dinosaur National Monument 攻略</a>对抬升与侵蚀讲得更深入。

## 恐龙足迹

恐龙足迹是 Red Fleet 的头号招牌，也是犹他州最了不起却最少有人听说的恐龙遗址之一。在靠近水库的一大片倾斜砂岩上，保存着**数百个恐龙脚印**——这些三趾足迹是恐龙在大约**两亿年前**的早侏罗世走过这片古老地表时留下的。和国家纪念地的化石骨骼不同，这些是遗迹化石：不是动物本身，而是活着的恐龙在行走时留下的直接印痕，因而有一种近乎不真实的临场感。

抵达足迹的过程本身就是体验的一部分。常见的方式有两种：

- **走步道。**一条徒步路线从公园的登山口出发，沿着水库通往恐龙足迹遗址。这是最直接的选择，但这是一段毫无遮挡的高原荒漠步行——要做好防晒并带足水。
- **走水路。**很多游客直接划皮划艇或桨板横渡水库，抵达恐龙足迹所在的岸边，这样能缩短陆地步行距离，也让这趟参观变成一场小冒险。水面平静时，这是当地人最喜欢的方式。

<div class="article-tip"><strong>保护足迹：</strong>这片恐龙足迹是不可替代的科学与文化资源。千万不要触摸、用粉笔描画、翻模，或者为了“让它更清楚”而往脚印上浇水，不要堆石头、不要涂鸦，也绝不要试图带走任何东西——盗取足迹和破坏行为已经毁掉过类似的遗址。看一看，拍照时保持尊重，让它保持你到来时的样子。当前的规定、步道距离和遗址通行情况<strong>请向官方渠道核实</strong>（Utah State Parks）。</div>

由于恐龙足迹出露在水边，能否抵达会受水库水位和现场条件影响。如果你打算专门围绕它安排行程，出发前请先向 Utah State Parks 确认当前情况。

## 水库上的水上活动

从本质上说，Red Fleet 是**自然意义上的一座水上乐园**——一座温暖、风景优美、为夏日而生的水库。它相对紧凑的面积和四周的红岩，让人觉得比浩瀚的 Flaming Gorge 更亲切、更有安全感，这也正是它吸引家庭和划船爱好者的一大原因。水库支持全套静水活动：游泳、皮划艇、桨板、独木舟、机动船和钓鱼，还有一个下水坡道和可供下水与休憩的岸线。

因为它比 <a href="/zh/guides/ultimate-guide-to-flaming-gorge/">Flaming Gorge</a> 更小也更靠近镇上，Red Fleet 是一次更轻松、投入更少的出行——到了几分钟就能下水，不用应付大水库的距离、风况和后勤问题。想要一整天的大水面航行和大鱼垂钓，可以看 Flaming Gorge 攻略；而如果想要悠闲划船、游个泳、再徒步去看恐龙足迹，Red Fleet 很难被超越。

## 皮划艇与桨板

划船大概是体验 Red Fleet 的最佳方式。水库尺度适中、四周有遮挡，无风的早晨水面平静；红色砂岩岩体构成壮观的背景；而且——这一点独一无二——在这里划船本身就可以是你前往恐龙足迹的路线。滑过水面，朝着一片有两亿年历史脚印的岸边而去，这种体验会让人记很久。

几点实用建议：

- **趁早出发。**早晨通常最平静；下午起风会让水面泛起波纹，划船和拍倒影都会更难。
- **穿好救生衣。**温暖的表层水下面是冷水，没有救生员，又是开阔水域，所有人都要穿救生衣，孩子尤其如此。
- **自带装备，或先确认租赁。**园内是否提供租赁会有变化——在指望能在公园租到皮划艇或桨板之前，<strong>请向官方渠道核实</strong>。
- **留意恐龙足迹那侧的岸边。**如果你划船去看足迹，上岸时要小心，并像徒步者一样尊重这处遗址。

## 游泳

在 Uintah Basin 炎热的夏日里，Red Fleet 的水库是实打实的解脱。整个季节里水温都会逐渐升高，有一片可以戏水和晒太阳的沙滩区域，红岩环境更是任何市政游泳池都比不了的。它之所以成为受欢迎的家庭游泳地点，正因为它温暖、好看又不难驾驭。

最关键的警告：**这里没有救生员。**要近距离看管孩子，让不会游泳的人穿着救生衣，并记住即使水面摸起来温暖，水温也会随深度下降。下水前当前的指定游泳区域、水况和各类季节性提示，<strong>请向官方渠道核实</strong>（Utah State Parks）。

## 钓鱼概览

Red Fleet 是一处让人愉快、门槛不高的渔场——它不像 Flaming Gorge 那样以大鱼闻名，但无论岸钓还是船钓都轻松，适合家庭。这座水库一般以**虹鳟**闻名，同时还有**鲈鱼**和**蓝鳃太阳鱼**等温水鱼种，让钓手在不同季节都有选择。它的面积让它特别适合新手和孩子——不用船，在岸边就能钓。

<div class="article-tip"><strong>下竿之前：</strong>必须持有有效的犹他州钓鱼执照，而且鱼种、放流、限额和法规会随时间和水域变化。在 Red Fleet 下竿之前，当前的鱼种、执照和限额<strong>请向官方渠道核实</strong>（Utah Division of Wildlife Resources）。想了解本区域标志性的大鱼垂钓，请看我们的 <a href="/zh/guides/ultimate-guide-to-flaming-gorge/">Flaming Gorge 攻略</a>，或者我们对<a href="/zh/fishing/">恐龙之乡钓鱼</a>的总览。</div>

## 露营

Red Fleet 在**水库附近设有营地**，这让一日游很容易变成过夜行程——在漆黑的荒漠星空下入睡，醒来时离水面只有几步，可以趁风起和人多之前先划一趟。在红岩旁露营，看着水库在日落时发亮，是一种非常美好的体验，也是本区域那些更热闹营地之外的安静选择。

由于**营位类型、配套设施、收费、预订窗口和季节性开放情况都会变动**，本攻略不会给出可能过时的具体信息。一些通用建议：

- 夏季**周末会订满**——尽量提前预订。
- 确认你想去的日期是**可预订还是先到先得**。
- 在指望某项设施（饮用水、卫生间、水电接口）之前，先确认它目前是否可用。

当前的营地详情和预订方式<strong>请向官方渠道核实</strong>（Utah State Parks 及预订系统）。关于高原荒漠露营的装备准备和昼夜大温差，请看我们的<a href="/zh/guides/what-to-bring/">装备清单攻略</a>。

## 徒步

Red Fleet 的徒步以**恐龙足迹步道**为核心，这是公园的招牌路线，从登山口出发，穿过高原荒漠地形，通往水库边缘的足迹遗址。大多数游客就是为这段徒步而来，而回报——一整面布满远古脚印的岩壁——无可比拟。除此之外，沿岸的短距离步行和在岩体周围的探索，也补齐了徒步的选项。

这是毫无遮挡的高原荒漠徒步：几乎没有阴凉、日照强烈、干热难耐，夏季尤其如此。带的水要比你以为需要的更多，做好防晒，暖季要早出发，并穿真正合脚的鞋子应对不平的岩面。出发前当前的步道距离、路况和恐龙足迹路线<strong>请向官方渠道核实</strong>（Utah State Parks）——另外记住，这里几乎没有手机信号可以依靠。

## 野生动物

对于一座小公园来说，Red Fleet 养育着相当丰富的高原荒漠与近水野生动物。在山艾和岩石之间，你可能看到**骡鹿**、**长耳大野兔**、**棉尾兔**、**蜥蜴**和各种荒漠鸟类，而水库则把**水禽**和其他鸟类吸引到岸边——这里很适合随性观鸟，尤其是在清晨和傍晚柔和的光线里。

和在高原荒漠的任何时候一样，给动物留出空间，绝不要投喂野生动物，在岩石地面上也要留意手脚放在哪里，因为本区域生活着**响尾蛇**。保持尊重的距离，让动物做它们自己。

## 摄影建议

Red Fleet 是给摄影师的礼物——戏剧性的红岩、能倒映的水面，而人比同等风景的地方少得多。

- **拍黄金时刻。**Navajo 砂岩“舰队”在日出和日落时发光；正午会让色彩变平。在这里，清晨和傍晚的光线就是一切。
- **在黎明追倒影。**清晨平静的水面会映出红色岩体——在起风之前出门，拍下那张招牌照片。
- **尊重地拍摄恐龙足迹。**用自然光和低角度拍出脚印的深度，但绝不要为了“让照片更好看”而用粉笔描、浇水或触摸脚印——那会破坏这处资源。
- **用划船的视角。**皮划艇或桨板能让你贴近水面，拍出岩体和岸线独特的低角度构图（注意保护器材不要进水）。
- **留意天空。**夏季的雷暴云能构成戏剧性的背景，但在开阔水面和裸露岩石上意味着雷击风险——雷暴逼近时立刻离开水面和高地。

## 季节建议

Red Fleet 主要是一个**暖季目的地**，各项活动都在水温升上来之后进入旺季。

- **夏季（旺季）。**游泳、划船和露营的最佳时段，水暖、白昼长。这也是最热闹、最炎热的时候——水上活动和恐龙足迹徒步都要趁早，避开午后的高温和风。
- **春季与秋季（平季）。**更凉爽、更安静、也很美，光线极佳，走去看恐龙足迹的路也更舒服。水温可能凉得不适合游泳，但划船、钓鱼、摄影和看足迹都很值得，而且人少。
- **冬季。**寒冷而安静，可玩的项目有限；部分设施和服务可能缩减或关闭。景色可能格外苍劲，但先确认哪些还开放。

<div class="article-tip"><strong>围绕高温和季节来安排：</strong>夏季高原荒漠的午后又热又晒。把恐龙足迹徒步或划船安排在早上，并在平季或冬季出行前确认设施的季节性状态。我们的 <a href="/zh/guides/vernal-weather-guide/">Vernal 天气攻略</a>逐月讲解了本区域的天气规律。当前的季节性开放时间和关闭情况<strong>请向官方渠道核实</strong>。</div>

## 家庭出行建议

Red Fleet 可能是 Vernal 一带最适合家庭的一站，因为它一次性满足了孩子们的诸多需求：**真实的恐龙脚印**、**可以游泳的温暖水库**、轻松的**岸边钓鱼**，还有一场**划船小冒险**——而且全都在一个紧凑、不费神的环境里。

想让家庭出行顺利：

- **趁早看足迹。**这段徒步毫无遮挡，要趁凉爽的早晨去，带上帽子、防晒霜和充足的水。
- **救生衣，一直穿。**没有救生员，表层之下是冷水——孩子在水边或水上都要穿救生衣。
- **把它讲成一个故事。**让孩子想象是什么恐龙留下了这些脚印；这会让遗址活起来，也和去国家纪念地看化石完美衔接。
- **为日晒和干燥做准备。**这里几乎没有阴凉；水和零食都要比预计的多带一些。

关于 Vernal 周边更完整的亲子计划，请看<a href="/zh/things-to-do/fun-things-to-do-vernal-utah-kids/">带孩子在 Vernal 好玩的事</a>；想看恐龙故事里化石的那一面，请看 <a href="/zh/dinosaur-national-monument/visiting-dinosaur-national-monument/">Dinosaur National Monument 攻略</a>。

## 无障碍信息

作为一座已开发的州立公园，Red Fleet 在日间使用区和营地一般提供无障碍停车位和基本设施，水库岸边和沙滩的大部分体验也离停车场不远。不过，**恐龙足迹步道是一条未铺装的高原荒漠路线，路面起伏不平**，而且无论是步行还是划船去看足迹，都会遇到并非处处无障碍的地形。

由于具体的无障碍设施和当前状况会因季节而变化，如果你有特定需求，出行前<strong>请向官方渠道核实</strong>（Utah State Parks）当前的无障碍安排。

## 一日行程建议

Red Fleet 只需要半天到一天，而且它和 Vernal 行程的其他部分搭得非常好。

- **清晨：**早点到，趁凉快直奔**恐龙足迹**——要么走步道徒步，要么划过平静的晨间水面到达遗址。拍照时保持尊重。
- **上午晚些时候：**回到主活动区，随着气温升高，在水库**游泳、划船或钓鱼**，以红色岩体为背景。
- **午餐：**在岸边或日间使用区野餐。
- **下午：**继续在水上待着，或者收拾好前往附近的目的地——<em>Steinaker State Park</em> 只有几分钟车程，<a href="/zh/dinosaur-national-monument/visiting-dinosaur-national-monument/">Dinosaur National Monument</a> 往东南开一小段就到。
- **黄金时刻：**如果你要住下，别错过天黑前落在“舰队”上的夕照和水面的倒影。

## 周末行程建议

只要住上一晚，Red Fleet 就成了一个更长周末行程里从容的锚点。

- **第 1 天 —— Red Fleet。**在营地扎营，上午去看恐龙足迹，下午游泳和划船，然后享受红岩日落和一夜暗空。
- **第 2 天 —— 恐龙及更多。**把你看到的足迹和 <a href="/zh/dinosaur-national-monument/visiting-dinosaur-national-monument/">Dinosaur National Monument</a> 的**化石**对照起来，凑齐完整的恐龙故事；或者往北去 <a href="/zh/guides/ultimate-guide-to-flaming-gorge/">Flaming Gorge</a> 的大水面，或去 <a href="/zh/guides/ultimate-guide-to-ashley-national-forest/">Ashley National Forest</a> 的高山地带。
- **可选第 3 天：**一次由向导带队的荒野冒险，或者体验 Vernal 及周边更多<a href="/zh/things-to-do/">好玩的事</a>。

<div class="article-tip"><strong>大本营策略：</strong>无论你是在 Red Fleet 露营，还是以住宿、餐饮和服务齐全的 Vernal 为基地，这座公园都很容易加进任何区域行程里。如果你从西边开车过来，我们的<a href="/zh/from/salt-lake-city/">盐湖城到 Vernal 攻略</a>把这条路线讲清楚了。</div>

## 行程规划要点

想让 Red Fleet 之行顺畅，有几件事要做对：

- **先确认收费和开放时间。**Red Fleet 是收费的州立公园，日间使用、露营和下水艇都要收费，开放时间随季节变化——出发前<strong>请向官方渠道核实</strong>（Utah State Parks）。
- **夏季露营要早订。**周末会订满；能提前订就提前订。
- **自带船只和装备**，除非你已经确认园内有租赁。
- **恐龙足迹放在早上。**这段路毫无遮挡，正午很热；趁早出发，带好防晒和水。
- **尊重足迹。**看一看、拍拍照，别去碰它们——破坏行为已经毁掉过类似的遗址，保护好它们才能让大家继续看到。
- **在 Vernal 加油和补给。**在镇上备齐；公园里的服务很有限。
- **搭配着玩。**Red Fleet 和附近的州立公园、国家纪念地，或者一天的山区或水库行程组合起来最出彩——把它编进更大的恐龙之乡计划，而不是当成孤立的一站。

Red Fleet State Park 是本区域藏在明处的最佳秘密——在这里你可以追着恐龙的脚印走，然后在几步之外的红岩水库里游泳，而且不用挤在人群里。给它一个早上，或者一整个周末，把那些会变动的细节核实清楚，再以 Vernal 作为整趟旅程的基地。当你准备好在恐龙之乡的行程里加上一段由向导带队的荒野冒险时，<a href="/zh/booking/">预订 Adventure Tours Vernal 的 UTV 行程</a>，让 Dave 和 Trudy 带你看看柏油路之外的这片土地。
